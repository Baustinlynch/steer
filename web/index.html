steer

Shows how much of your Claude Code time was you and how much was the agent working by itself. Made for Hack Club's AI time tracking bounty.

Live tracking

Install steer once and it tracks Claude Code, Codex, OpenCode, Copilot and Cursor while you work. Your page at steer.duck.hackclub.app/u/your-name updates as you go.

Mac and Linux:

curl -fsSL https://steer.duck.hackclub.app/install.sh | sh

Windows (PowerShell):

irm https://steer.duck.hackclub.app/install.ps1 | iex

Prompt text never leaves your computer, only counts like how many words it had and whether it said what happened when you tested something. The code is at github.com/EwoudVV/steer. To undo everything: ~/.steer/bin/steer setup --remove

Or check your old Claude Code logs

Claude Code keeps them in a hidden folder:

  • Mac and Linux: ~/.claude/projects
  • Windows: %USERPROFILE%\.claude\projects

In the folder picker, press Cmd+Shift+G on a Mac and paste the path, or paste it into the address bar on Windows. To drag it from Finder instead, press Cmd+Shift+. to show hidden folders.
